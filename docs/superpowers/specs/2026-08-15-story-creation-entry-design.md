# 故事创作入口与资产生产流程设计

## 目标

在 `/stories` 的输入框下新增三个 large 创作入口，并为创建、沉浸式创作、上传故事建立统一的资产创建与编辑路由流程。

本阶段的入口只负责启动流程和进入正确的编辑模块；具体编辑页内容、Agent 分析能力和文件解析能力沿着这些路由继续建设。

## 入口模块

三个入口横向排列在故事输入框下方，使用统一尺寸、统一交互和现有故事工作台主题：

| 入口 | 图标 | 触发行为 | 首个页面 |
| --- | --- | --- | --- |
| 故事创建 | 文件夹 | 创建普通故事资产 | `/stories/:id/outline` |
| 沉浸式创作 | 电影 | 创建沉浸式故事资产 | `/stories/immersive/:id/outline` |
| 上传故事 | 导入 | 打开文件选择器，选择成功后创建并导入资产 | `/stories/:id/outline` |

按钮采用语义化链接或按钮：前两个入口是异步创建后跳转的按钮，上传入口是按钮并绑定隐藏的文件 input。整块 large 卡片可点击，图标、标题和 hover/focus 状态与故事工作台视觉规范保持一致。

## 路由结构

普通故事资产使用以下模块路由：

- `/stories/:id/outline`：大纲
- `/stories/:id/roles`：角色资产
- `/stories/:id/worldview`：世界观设定
- `/stories/:id/story`：故事页

沉浸式故事资产使用同一组模块，但增加 `/stories/immersive` 前缀：

- `/stories/immersive/:id/outline`
- `/stories/immersive/:id/roles`
- `/stories/immersive/:id/worldview`
- `/stories/immersive/:id/story`

所有创建入口默认先进入 `outline`，后续由编辑页内部导航切换到 `roles`、`worldview` 和 `story`。

## 资产创建与标题生命周期

### 普通故事和沉浸式创作

1. 用户点击入口。
2. 前端调用现有故事项目创建接口，在当前空间创建资产。
3. 创建请求使用幂等键，避免重复点击生成多个资产。
4. 创建成功后，根据创作类型跳转到对应的 `outline` 路由。
5. 创建初始标题使用临时标题：普通故事为“未命名故事”，沉浸式创作为“未命名沉浸式故事”。

### Agent 命名

当流程进入 `/story` 故事生产页时，如果资产仍使用临时标题，则调用 Agent 生成多个候选故事名，并将返回的第一个候选名写回当前故事资产，作为整个资产的标题。

命名请求必须具备幂等保护：刷新故事页或重复进入故事页不能不断改名。Agent 调用失败时保留临时标题，页面仍可继续使用；用户后续可在资产标题编辑能力上线后手动修改。

## 上传故事流程

1. 用户点击“上传故事”。
2. 立即打开文件选择器。
3. 文件选择成功后，先创建普通故事资产并取得 `id`。
4. 创建成功后进入 `/stories/:id/outline`，页面展示导入进度。
5. 对上传文件进行文字解析。
6. 按顺序执行导入：
   - Agent 分析并导入大纲；
   - Agent 分析并导入角色资产；
   - Agent 分析并导入世界观设定；
   - 将文件解析出的正文文字导入故事页。
7. 每个阶段独立保存结果和状态，单个阶段失败时保留已完成阶段，并允许继续或重试，不回滚已成功导入的数据。

文件选择器只负责取得文件；实际上传、解析和 Agent 分析通过故事资产导入服务完成。当前没有可用的分析接口时，先保留明确的服务调用边界和加载状态，不在前端伪造分析结果。

## 状态与错误处理

- 创建中：入口按钮进入 loading 状态，防止重复触发。
- 创建失败：停留在 `/stories`，展示可重试的错误提示，不产生本地假项目。
- 文件未选择：不创建资产，保持入口初始状态。
- 文件类型或大小不支持：在文件选择后立即提示，不进入创建流程。
- 上传或解析失败：进入已创建资产的 outline 页，展示失败阶段和重试入口。
- Agent 命名失败：继续使用临时标题，不阻塞故事生产。

## 实现边界

第一步实现三个入口、入口图标、点击状态和创建后路由跳转，并补齐普通/沉浸式四模块路由壳。上传入口先完成文件选择和流程状态承载，解析与 Agent 分析使用清晰的服务接口边界接入，不把分析逻辑散落在按钮组件内。

## 验证

- 验证三个入口在暗色和亮色主题下的布局、hover、focus 和 disabled 状态。
- 验证普通故事与沉浸式故事创建后分别进入正确的 outline 路由。
- 验证重复点击不会创建重复资产。
- 验证取消选择文件不会创建资产。
- 验证上传流程可以按 outline、roles、worldview、story 顺序展示状态。
- 验证故事生产页只在临时标题状态触发一次 Agent 命名。
- 运行 Web workspace 的 typecheck、测试和 `git diff --check`。
