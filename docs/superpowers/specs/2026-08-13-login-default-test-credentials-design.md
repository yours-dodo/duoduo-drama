# 登录页默认测试凭据设计

## 状态

已确认，进入实现。

## 目标

开发环境打开登录页时，默认展示账户密码登录，并预填固定的开发测试账号和密码，减少后续页面联调的重复输入。

## 约束

- 暂不增加注册按钮或注册组件。
- 保留邮箱验证码登录及密码找回入口。
- 测试凭据只允许从本地 Astro 开发环境变量读取，生产构建保持空白。
- 不修改服务端认证协议；页面仍调用现有密码登录接口。

## 页面行为

- 初始激活 `password` 登录面板，验证码面板默认隐藏。
- 开发环境默认填入：
  - 邮箱：由 `DEV_TEST_ACCOUNT_EMAIL` 提供
  - 密码：由 `DEV_TEST_ACCOUNT_PASSWORD` 提供
- 非开发环境不输出默认账号和密码值。
- 用户仍可切换到验证码登录，或进入忘记密码流程。

## 验证

- 检查 Astro 页面类型和构建。
- 检查开发环境默认值与生产环境空值的模板逻辑。
- 检查登录页现有模式切换脚本不受影响。
