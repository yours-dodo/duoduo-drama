# 故事项目资产工作区重排设计

## 1. 背景

当前 `/stories` 已经使用 Vue Router，并且项目编辑页具备 Header、右侧常驻 AI 对话和模块路由。本次不调整根页面的信息架构，根页面继续保留现状：

```text
/stories
├── 创作空间
├── 沉浸式创作
├── 模版库
└── 最近
```

项目编辑页需要从“通用子路由页面”重排为围绕故事资产生产的工作区。核心资产关系为：

```text
故事项目
├── worldview 世界观
├── roles 角色资产
├── outline 大纲
└── story 故事正文
```

大纲内部的故事线、章节、场景卡属于后续阶段，本次只为大纲保留一级模块入口，不提前展开其内部层级。

## 2. 目标与非目标

### 目标

- 编辑页 Header 统一展示四个一级资产入口：世界观、角色资产、大纲、故事正文。
- 普通项目和沉浸式项目使用同一套资产导航与内容工作区。
- 四个模块共享统一的编辑页外壳，右侧 AI 对话始终常驻。
- 通过中文展示名明确资产职责，同时保留稳定的英文路由标识。
- 保持现有根页面、作品列表、创建流程、最近对话和 Vue Router 行为不变。

### 非目标

- 不在本次实现故事线、章节、场景卡的树形导航或编辑器。
- 不重做 `/stories` 根页面的系统导航、作品卡片、输入框或创建按钮。
- 不改变普通项目和沉浸式项目的路由前缀。
- 不在 Web 层新增业务规则、数据库模型或 Agent 编排逻辑。

## 3. 信息架构

### 根页面

根页面维持当前结构。项目编辑页通过作品卡或创建流程进入，不将项目资产导航混入根页面的“最近”区域。

### 项目编辑页

项目编辑页隐藏系统级左侧目录，Header 作为项目内部的一级资产导航：

```text
Header
┌ Logo ─ 世界观 ─ 角色资产 ─ 大纲 ─ 故事正文 ─ 工具区
```

当前模块使用现有的无背景选中态：主题色、加粗、下边框；不使用背景块、圆角或额外的左侧高亮条。

Header 只负责一级资产切换。后续大纲内部的故事线、章节、场景卡应属于大纲模块自身的内容导航，不回填到 Header。

### 路由映射

普通项目：

```text
/stories/:id/worldview   世界观
/stories/:id/roles       角色资产
/stories/:id/outline     大纲
/stories/:id/story       故事正文
```

沉浸式项目：

```text
/stories/immersive/:id/worldview   世界观
/stories/immersive/:id/roles       角色资产
/stories/immersive/:id/outline     大纲
/stories/immersive/:id/story       故事正文
```

路由标识保持 `worldview`、`roles`、`outline`、`story`，只更新中文展示文案：

| Route module | Display label | Responsibility |
| --- | --- | --- |
| `worldview` | 世界观 | 故事发生的规则、背景、空间与设定 |
| `roles` | 角色资产 | 角色信息、关系、动机与角色变化 |
| `outline` | 大纲 | 故事结构、事件推进与后续结构化入口 |
| `story` | 故事正文 | 章节正文、段落内容与版本结果 |

## 4. 统一编辑工作区

四个模块共享同一套页面外壳：

```text
项目 Header
┌──────────────────────────────┬──────────────┐
│ 当前模块内容                  │ AI 对话区      │
│                              │ 历史           │
│ 模块标题 / 说明 / 编辑区域     │ 输入           │
└──────────────────────────────┴──────────────┘
```

### 外壳职责

- 读取当前路由模块并标记 Header 选中状态。
- 保持项目编辑页的深色编辑室主题、统一版心和安全边距。
- 右侧聊天区从模块切换时保持常驻，不因 RouterView 切换而销毁。
- 页面模块切换使用客户端导航，不触发整页刷新。

### 模块职责

四个模块先提供清晰、可扩展的内容边界：

- 世界观：展示“设定条目”或世界观文档编辑入口；内容重点是规则、空间、历史和限制。
- 角色资产：展示角色资产集合及角色详情入口；内容重点是角色目标、动机、关系和变化。
- 大纲：展示大纲工作区；本次只建立大纲模块容器和编辑入口，不显示故事线、章节、场景卡树。
- 故事正文：展示正文生产区；为章节正文与段落版本预留编辑容器，但本次不实现完整正文编辑器。

内容模块不直接负责聊天历史和项目级导航，避免切换模块时重复创建聊天状态。

## 5. 交互与状态

### 一级导航

- 点击 Header 资产入口只调用 Vue Router `push`。
- 当前路由模块通过 `route.params.module` 或路由 meta 映射。
- 无效模块继续由路由守卫回退到 `outline`。
- 当前模块入口需要提供 `aria-current="page"`，选中态不能只依赖颜色。

### 项目模式

- 普通项目和沉浸式项目共用模块标签、内容外壳和聊天区。
- 模块导航根据当前模式保留对应前缀，不能跳到另一种项目模式。
- 项目根路径仍重定向到 `/outline`。

### 加载、空状态和错误

- Header、资产导航和聊天区属于工作区壳层，优先保持可见。
- 模块内容区可以显示骨架屏，不使用突兀的全页“正在铺开”状态。
- 暂无内容时显示模块说明和下一步入口，不伪造业务数据。
- API 错误在当前模块内容区展示，可重试；不影响 Header 导航和聊天区。

## 6. 组件边界

建议保留并收敛现有组件边界：

- `StoryWorkspaceApp.vue`：项目工作区布局、RouterView、常驻 Chat。
- `StoryWorkspaceHeader.vue`：Logo、四个资产导航、项目级工具区。
- `StoryChatPanel.vue`：聊天历史和输入区，模块切换时保持挂载。
- `StoryProjectView.vue`：根据 `route.meta.module` 选择模块内容；后续可拆分为四个模块组件。
- `router.ts`：模块标识、路由映射、模式前缀和非法模块回退。

本次不把根页面的 `StoryApp.vue` 与项目模块内容混合；根页面继续承担作品索引和创作入口，项目页面承担资产编辑工作区。

## 7. 后续扩展边界

大纲模块后续独立扩展为：

```text
outline
├── 故事线
├── 章节
└── 场景卡
```

扩展时优先在大纲模块内容区增加内部导航或树形结构，不修改项目 Header 的四个一级资产入口。故事正文后续通过章节和场景卡引用生成内容，并在正文区管理段落版本。

## 8. 验收标准

- `/stories` 的“创作空间、沉浸式创作、模版库、最近”视觉和行为保持现状。
- 普通项目和沉浸式项目 Header 均按“世界观、角色资产、大纲、故事正文”顺序展示。
- 四个一级入口均能通过 Vue Router 切换，地址栏前缀和项目模式正确。
- 项目编辑页不再显示系统级左侧目录，右侧聊天区在四个模块之间切换时保持常驻。
- 当前模块具备可访问的选中态和正确中文标题。
- 不提前显示故事线、章节、场景卡导航。
- Web 测试、类型检查、构建和目标路由浏览器检查通过。
