# 横轴时间轴直接分支设计

## 目标

优化横轴时间轴的共享分支几何：移除父节点出口到公共垂直分支线之间的水平引线，使公共分支线直接从父节点边界开始展开。

修改前：

```text
父节点 ────┬──── 子节点 A
           └──── 子节点 B
```

修改后：

```text
父节点 ┬──── 子节点 A
       └──── 子节点 B
```

## 范围

- 仅修改 `timeline-horizontal` 视图中的共享分支路由。
- 水平主轴、普通单边语义关系、纵轴时间轴、鱼骨图、逻辑图和思维导图不改变。
- 节点坐标、层级间距、兄弟间距和碰撞处理不改变。

## 几何规则

1. 共享分支的公共垂直 backbone 使用父节点出口点的 X 坐标。
2. backbone 的第一个有效线段从父节点边界沿 Y 轴直接延伸，不再先沿 X 轴移动。
3. 每个子节点仍通过 `backbone → 子节点` 的水平 twig 连接。
4. 父节点从 north、south 或 east 侧出线时均遵守同一规则。
5. 路由继续保持正交；现有圆角半径和分支共享机制保持不变。
6. 连线端点必须继续与 VueFlow 端口边界点一致。

## 实现边界

修改 `getSharedBranchRouteGeometry`：将当前根据父子间距计算的 `spineX` 改为父节点边界出口 `sourcePoint.x`。保留现有 owner 选择、backbone/twig 构造、点去重和隐藏语义边逻辑。

不在渲染层裁剪或遮盖旧引线，确保路由坐标、命中区域和视觉路径一致。

## 验证

- 更新横轴布局测试，断言共享分支 backbone 与父节点出口具有相同 X 坐标。
- 继续断言所有分支路径为正交路径。
- 继续断言路由首尾点与对应端口边界点一致。
- 运行 Web 测试、类型检查、构建与横轴页面浏览器检查。

## 完成标准

- 横轴共享分支从父节点边界直接展开，无水平引线。
- 子节点侧水平连线、圆角和公共分支结构正常。
- 其他布局视图没有行为变化。
