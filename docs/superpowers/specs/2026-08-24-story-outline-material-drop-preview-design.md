# 大纲物料拖拽虚影预览设计

## 背景

大纲画布的剧情物料已经支持拖到 Story、幕、章节或 Beat 节点后建立真实父子关系，但当前拖动阶段只高亮目标节点。用户无法在松手前判断新物料会出现在哪里，也看不到即将建立的连接关系。

本次增加 VueFlow 内的临时虚影节点和预览连线，使拖拽在命中合法目标后提前显示占位结果。

## 目标

- 命中合法结构节点时立即显示虚影物料盒子。
- 提前显示父节点到虚影盒子的连接线。
- 虚影位置复用当前视图的确定性布局算法。
- 真实节点在拖动期间保持稳定，不因预览反复重排。
- 预览不写入大纲文档、不触发自动保存，也不改变选择。
- 离开目标、拖到空白区、取消拖动或完成 drop 时可靠清除预览。

## 非目标

- 不允许用户直接拖动虚影节点。
- 不支持在空白区预览自由节点。
- 不允许物料节点成为预览目标。
- 不修改五种布局算法的方向和间距规则。
- 不持久化预览位置或预览状态。

## 方案选择

采用“临时布局节点 + VueFlow 临时边”方案：

1. 画布命中合法目标后，上报物料类型和目标节点 ID。
2. 工作区在只读的 OutlineDocument 副本中增加固定 ID 的临时节点和临时关系边。
3. 使用现有 `buildOutlineLayout()` 计算包含临时节点的预览布局。
4. 画布只从预览布局提取临时节点和临时边，不替换真实节点的位置。
5. 通过父节点坐标差对预览节点和路由整体平移，使连线锚定当前画布中的真实父节点。

未采用：

- 固定偏移预览：无法适配横轴、纵轴、鱼骨图、逻辑图和思维导图。
- 整图实时预览重排：结果精确但会造成已有节点频繁跳动，拖拽目标容易抖动失焦。

## 数据流

### 预览请求

`StoryOutlineCanvas` 新增事件：

```ts
preview-material: [payload: {
  type: NarrativeCanvasAssetType;
  parentId: string;
} | null]
```

只有目标 ID 或物料类型发生变化时才发出新请求，避免每次 `dragover` 都重新布局。

### 临时文档

`StoryOutlineWorkspace` 保存纯 UI 状态 `materialPreviewRequest`，并从现有 `outlineDocument` 派生预览文档：

- 临时节点 ID：`__narrative-material-preview__`
- 临时边 ID：`__narrative-material-preview-edge__`
- `parentId`：当前命中结构节点 ID
- `type`：当前拖动物料类型
- `title`：对应物料标签，例如“事件占位”
- `summary`：固定提示“松手添加”

临时节点只存在于 computed 派生值中，不修改 `NarrativeDocument.assets`。

### 预览布局

预览文档使用当前视图、当前真实节点和当前 `positionOverrides` 调用 `buildOutlineLayout()`。工作区把预览布局、临时节点 ID、临时边 ID 和父节点 ID 传给画布。

预览清除后 computed 值立即恢复 `null`。

## VueFlow 渲染

### 虚影节点

临时节点使用现有 `StoryOutlineFlowNode` 渲染，但数据中增加 `isMaterialPreview`：

- `draggable = false`
- `selectable = false`
- `focusable = false`
- `deletable = false`
- `aria-hidden = true`
- 半透明背景、虚线边框和轻微呼吸效果
- 保留物料类型标签和“松手添加”提示

虚影节点与真实节点位于同一个 VueFlow 实例，不使用画布外绝对定位盒子。

### 预览位置稳定

预览布局可能为碰撞避让而移动父节点。画布计算：

```text
delta = 当前父节点位置 - 预览布局父节点位置
```

把临时节点位置和临时边路由点整体加上 `delta`，使预览相对父节点保持布局算法给出的方向和间距，同时不移动真实节点。

### 预览连线

预览边使用现有 VueFlow 自定义边渲染：

- 复用预览布局生成的 edge route 和 port。
- 给真实父节点临时追加预览 source port，给虚影节点提供 target port。
- 路由点使用与虚影节点相同的 `delta` 平移。
- 使用虚线、低透明度和物料类型强调色。
- 不显示箭头和边标签，避免视觉噪声。
- `selectable`、`focusable`、`deletable` 均为 `false`。

如果当前视图没有生成可用的 routed edge，则降级为 VueFlow 内置 `smoothstep` 临时边；不使用画布外 SVG。

## 状态清理

以下情况必须同时清除目标高亮和预览请求：

- 指针离开合法目标进入空白区。
- 指针进入已有物料节点。
- `dragend`。
- `drop` 成功或失败。
- 布局视图在拖动期间发生切换。
- 组件卸载。

成功 drop 的顺序为：先清除预览，再发出真实新增事件。真实节点生成后由正常布局和自动保存流程接管。

## 性能

- `dragover` 仍负责坐标命中，但只有预览 key（`type + parentId`）变化时才更新工作区状态。
- 布局计算通过 Vue computed 缓存。
- 临时节点和临时边数量恒定为 1。
- 不在每个鼠标移动事件中复制或保存 NarrativeDocument。

## 可访问性与动效

- 虚影节点和预览边不进入键盘顺序和辅助技术交互树。
- 合法目标仍保留现有高亮反馈。
- `prefers-reduced-motion` 下关闭虚影呼吸动画，仅保留静态虚线边框。
- 拖动物料按钮的现有文本和 ARIA 标签保持不变。

## 测试设计

### 纯函数测试

提取预览投影函数，覆盖：

- 从预览布局提取临时节点和临时边。
- 根据父节点坐标差平移节点和全部路由点。
- 保持端口 ID、边 ID、类型和父节点关系。
- 缺少临时节点、父节点或路由时返回安全降级结果。
- 不修改输入布局对象。

### 适配测试

- 预览文档只增加一个临时节点和一个临时边。
- 原 OutlineDocument 节点和边数组不被修改。
- 清除请求后预览布局为 `null`。

### 浏览器验证

桌面和 700px 窄屏分别验证：

- 拖到章节或 Beat 时出现虚影盒子、目标高亮和虚线连接。
- 切换到另一个合法节点时虚影移动且只存在一个。
- 拖到空白区或已有物料节点时虚影消失。
- `dragend` 后虚影消失且节点数量不变。
- 成功 drop 后虚影被真实节点替换，父子边正确。
- 页面无运行时错误和横向溢出。

## 完成标准

- 合法目标上能提前看到 VueFlow 虚影节点和预览边。
- 预览位置由当前布局算法计算，真实节点拖动期间保持稳定。
- 所有退出路径都能清除预览，不产生残留节点或边。
- 预览不进入保存数据，不触发自动保存。
- Web 测试、类型检查、Lint、格式检查、构建和差异检查通过。
- 桌面及窄屏真实拖拽验证通过。
