# 大纲物料节点吸附拖放设计

## 背景

大纲画布底部的剧情物料目前只携带物料类型和鼠标落点。创建后的物料没有保存目标节点关系，转换为 VueFlow 文档时只能默认挂到 Story 根节点，因此把物料拖到任意画布位置都会表现为挂到第一个节点。

本次调整将拖放从“在画布坐标创建自由节点”改为“把物料挂到明确命中的叙事节点”。

## 目标

- 物料只在拖放命中 Story、幕、章节或 Beat 节点时创建。
- 新物料保存实际目标节点 ID，并在所有布局视图中作为该节点的子节点参与布局。
- 拖到画布空白区域、其他物料节点或无效目标时不创建。
- 拖动经过合法目标时提供明确的吸附高亮反馈。
- 旧大纲数据无需迁移即可继续读取。

## 非目标

- 不支持物料挂到另一个物料下。
- 不引入自由连线、物料间层级或最近邻自动猜测。
- 不改变时间轴、鱼骨图、逻辑图和思维导图的布局算法方向。
- 不改变物料编辑表单或新增其他物料类型。

## 方案选择

采用画布坐标命中方案：将屏幕拖放坐标转换为 VueFlow 坐标，再与当前布局中各节点的 bounding box 比较。

未采用以下方案：

- DOM `event.target` 命中依赖 VueFlow 内部 DOM 和节点子元素，交互结构变化后容易失效。
- 最近节点吸附会在空白区域误创建，与“只有覆盖节点才创建”的产品规则冲突。

## 数据模型

`NarrativeAssetReference` 新增可选字段：

```ts
parentId?: string;
```

规则：

1. 新建画布物料必须写入合法结构节点的 ID。
2. 结构节点包括 Story、Arc、Chapter 和 Beat。
3. 旧数据缺少 `parentId` 时按 Story 根节点处理。
4. `parentId` 不存在或指向非结构节点时按 Story 根节点处理，避免产生不可见孤儿。
5. `narrativeDocumentToOutline()` 使用解析后的父节点生成 `parentId` 和 relation edge，不再固定使用 Story 根节点。

数据结构保持当前 schema version；新增字段为向后兼容的可选字段，不要求一次性迁移历史内容。

## 拖放交互

### 可接收目标

- Story
- 幕（Arc）
- 章节（Chapter）
- Beat

剧情物料节点本身以及无法映射到叙事结构的节点不可接收。

### 命中规则

1. `dragover` 和 `drop` 都把 `clientX/clientY` 转换为 VueFlow 坐标。
2. 使用当前布局节点的 `x/y/width/height` 判断指针是否落在节点矩形内。
3. 多个矩形异常重叠时，优先选择面积最小且层级更深的合法结构节点；在现有固定节点尺寸下等价为优先更深节点。
4. 未命中合法节点时清除反馈，`drop` 不发出新增事件。

### 视觉反馈

- 进入合法节点时给该节点增加目标态 class，显示边框和轻量外发光。
- 离开节点、取消拖动、完成 drop 或 dragend 时立即清除目标态。
- 工具栏文案从“拖入画布”调整为“拖到节点”，按钮无障碍标签同步描述目标要求。

### 创建和布局

成功 drop 上报：

```ts
{
  type: NarrativeCanvasAssetType;
  parentId: string;
}
```

工作区创建物料时写入 `parentId`。不再把鼠标落点写入 `positionOverrides`，避免新节点与目标节点重叠；新物料由当前确定性布局算法在目标节点的子树中排布。创建后选中新物料，现有自动保存机制负责持久化。

## 删除兼容

删除幕或章节后，可能存在指向已删除结构节点的物料。转换大纲时必须校验 `parentId`；失效引用回退到 Story 根节点。物料本身不会因为结构节点删除而丢失。

这次不改变已有的幕迁移和章节级联删除规则。

## 测试设计

### 快速回归测试

提取无 UI 副作用的目标命中函数，输入布局节点、结构节点 ID 集合与画布坐标，覆盖：

- 指针命中指定章节时返回该章节，而不是第一个节点。
- 指针落在空白区时返回 `null`。
- 指针命中剧情物料节点时返回 `null`。
- 重叠候选中优先返回更深的结构节点。

### 数据适配测试

- 带 `parentId` 的物料生成从目标节点到物料的 relation edge。
- 无 `parentId` 的旧物料仍挂到 Story。
- 无效或指向物料的 `parentId` 回退到 Story。

### 页面验证

在桌面和窄屏尺寸验证：

- 拖到不同章节或 Beat，物料分别出现在对应子树中。
- 拖到空白区不会新增。
- 拖到已有物料不会新增。
- 拖动目标高亮能正确出现和清除。
- 新增后切换布局和刷新页面，父子关系保持不变。

## 完成标准

- 不再存在“拖到任意位置却挂到第一个节点”的行为。
- 只有明确命中的结构节点能接收物料。
- 物料关系持久化，刷新和切换布局后保持一致。
- 相关单元测试、Web 测试、类型检查、Lint、格式检查和构建通过。
- 桌面与窄屏浏览器检查通过。
