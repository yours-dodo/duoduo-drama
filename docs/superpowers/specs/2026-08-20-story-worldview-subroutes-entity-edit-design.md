# 世界观子路由与实体独立编辑页设计

## 状态

- 日期：2026-08-20
- 状态：用户已确认交互设计，等待书面规格复核
- 范围：标准故事项目的世界观页面

## 1. 目标

让世界观一级 Tab 和实体编辑状态都由 URL 唯一决定：

- 访问设定路由时直接落到“设定文档” Tab。
- 访问世界构成路由时直接落到“世界构成” Tab。
- 实体编辑从抽屉迁移到独立页面。
- 实体保存或删除成功后返回世界构成页。

拆分后，刷新、复制链接、浏览器前进后退和直接访问都应恢复同一个页面状态。

## 2. 路由契约

| 路由 | 页面结果 |
| --- | --- |
| `/stories/{projectId}/worldview` | 重定向到设定文档 |
| `/stories/{projectId}/worldview/settings` | 世界观页面，选中“设定文档” |
| `/stories/{projectId}/worldview/composition` | 世界观页面，选中“世界构成” |
| `/stories/{projectId}/worldview/composition/{entityId}/edit` | 独立实体编辑页 |

本次沿用已经确认的 `settings` 和 `composition` 路由词，不修改为其他英文名称。

非法世界观子路由重定向到：

```text
/stories/{projectId}/worldview/settings
```

实体编辑路由中的实体不存在时不重定向到其他实体，编辑页展示未找到状态和“返回世界构成”入口。

## 3. Tab 行为

当前组件本地 `mode` 不再是页面状态源。

路由映射为：

```text
settings     → document UI → 设定文档 Tab
composition  → ontology UI → 世界构成 Tab
```

两个 Tab 使用路由链接：

- 点击“设定文档”导航到当前项目的 `/worldview/settings`。
- 点击“世界构成”导航到当前项目的 `/worldview/composition`。
- 当前选中状态从路由计算。
- 浏览器前进或后退时，Tab 和内容同步更新。
- 刷新任一路由后直接显示对应 Tab，不先闪现默认 Tab。

顶部“世界观”主导航在所有世界观子路由和实体编辑路由下保持选中。

## 4. 实体编辑页

### 4.1 入口

世界构成页的以下操作进入独立编辑路由：

- 实体目录中的“编辑”。
- 当前选中实体详情中的“编辑”。
- “新增实体”创建本地草稿实体后进入该实体的编辑路由。

实体 ID 必须使用 URL 编码后写入路由。

### 4.2 页面结构

实体编辑页继续复用现有结构化实体编辑器，包括：

- 通用字段。
- 地点、组织、角色或规则类型字段。
- 补充说明富文本。
- 字段校验。
- 保存按钮。

原抽屉外壳、遮罩层和关闭按钮移除。新页面增加：

- 实体类型和名称标题。
- “返回世界构成”操作。
- “删除实体”操作。
- 编辑状态提示。

### 4.3 保存

保存流程：

```text
提交表单
  → 运行现有实体校验
  → 校验失败时停留编辑页并显示字段问题
  → 校验成功时更新统一知识图中的实体
  → 使用 replace 导航到 /worldview/composition
```

保存成功使用路由替换而不是追加历史记录，避免用户按浏览器返回键再次进入已经完成的旧编辑页。

### 4.4 删除

删除前继续检查实体引用：

- 有事实或其他实体引用时，删除失败并停留在编辑页。
- 没有引用时，从统一知识图移除实体。
- 删除成功后使用 `replace` 返回 `/worldview/composition`。

### 4.5 返回和取消

用户主动点击“返回世界构成”时导航到 `/worldview/composition`。本次不新增未保存离开确认框，保持现有抽屉关闭时放弃本地表单草稿的行为。

新增实体在进入编辑页前已经加入当前原型知识图；用户返回时该草稿实体继续保留，行为与当前新增后关闭抽屉一致。

## 5. 状态边界

当前世界观知识图由页面组件创建。如果世界构成页和实体编辑页各自创建一份知识图，会出现以下错误：

- 编辑页找不到刚刚创建的实体。
- 保存后返回世界构成页看不到修改。
- 删除后列表重新出现实体。

因此实现时需要把当前原型知识图提取为按 `projectId` 隔离的共享状态。世界构成页和实体编辑页读取同一个项目状态。

共享状态只解决本次前端路由切换。它不替代 Server 持久化；浏览器完整刷新后仍按当前原型种子重新初始化。后续接入数据库时，共享状态层替换为 Server 数据加载和写入，不改变本次路由契约。

## 6. 组件边界

### 路由层

- 注册世界观默认重定向、两个 Tab 路由和实体编辑路由。
- 为世界观路由设置稳定的模块元数据。
- 校验世界观视图参数。

### 项目页面层

- 普通世界观子路由渲染世界观工作区。
- 实体编辑路由渲染独立实体编辑页。
- 其他故事模块渲染逻辑保持不变。

### 世界观工作区

- 从路由计算当前 Tab。
- Tab 点击执行路由导航。
- 编辑和新增操作进入实体编辑路由。
- 不再管理 `editingEntityId` 和实体抽屉。

### 实体编辑页

- 从 `projectId` 和 `entityId` 读取共享项目知识图。
- 复用实体编辑表单。
- 负责保存、删除、未找到和返回行为。

### 共享世界观状态

- 按项目 ID 创建或读取知识图。
- 暴露实体查找、新增、替换和删除能力。
- 不负责路由和页面展示。

## 7. 错误处理

| 场景 | 行为 |
| --- | --- |
| 非法世界观 Tab | 重定向到 `/worldview/settings` |
| 实体不存在 | 显示未找到页面，不打开其他实体 |
| 实体校验失败 | 停留编辑页并显示字段错误 |
| 实体仍被引用 | 停留编辑页并显示引用阻止删除的信息 |
| 路由直接刷新 | 从当前项目知识图重新查找实体 |

## 8. 测试要求

### 路由测试

- `/worldview` 重定向到 `/worldview/settings`。
- `/worldview/settings` 解析为设定文档。
- `/worldview/composition` 解析为世界构成。
- `/worldview/composition/{id}/edit` 正确读取项目 ID 和实体 ID。
- 非法世界观子路由重定向到设定文档。
- 原有 basic、roles、outline 和 story 路由不受影响。

### 交互测试

- 直接访问两个 Tab 路由会选中对应 Tab。
- 点击 Tab 同步改变 URL 和内容。
- 点击实体编辑进入独立编辑页。
- 保存失败时停留编辑页。
- 保存成功后返回世界构成页。
- 删除被引用实体时停留编辑页。
- 删除成功后返回世界构成页。
- 不存在的实体显示未找到状态。
- 编辑保存后，世界构成页显示更新后的实体。
