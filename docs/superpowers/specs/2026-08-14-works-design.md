# 作品广场 Demo 设计

## 目标

在 Web 端新增一个纯前端 Vue 作品广场 Demo，不改动 Server 或数据库。作品广场提供低权重的基础搜索、以卡片为主的无限虚拟滚动列表，以及通过独立 URL 访问的沉浸式作品详情。

## 路由与目录

- `apps/web/src/workspaces/works/`：Vue 作品广场 workspace，目录名保持英文。
- `/works`：作品卡片列表模式。
- `/works/:workId`：沉浸式作品详情模式。
- 两个 Astro 路由都挂载同一个 `WorksApp.vue`。卡片链接由 Vue 拦截并调用 `history.pushState`，因此在列表与详情之间切换时只更新路由地址和页面状态，不触发整页刷新；直接刷新详情 URL 仍可加载对应作品。
- 首页公共导航的“作品广场”指向 `/works`。

## 交互设计

### 模式一：作品列表

- 深色阅读室风格，卡片网格是视觉主体。
- 搜索收纳在顶部工具栏，占用较低视觉权重；按标题、作者、类型和标签匹配。
- 使用固定卡片高度、响应式列数和上下缓冲行计算虚拟窗口，只渲染视口附近的卡片。
- Demo 数据由前端本地数据生成，按批次追加到已加载集合，滚动接近底部时继续加载，直到本地样本耗尽。
- 无匹配时显示明确的空状态，并提供清除搜索操作。

### 模式二：沉浸式详情

- 使用全屏暗色舞台，作品封面与标题形成主视觉，元数据、标签、简介和章节摘要作为辅助信息。
- 提供“返回作品广场”链接；浏览器后退/前进通过 `popstate` 同步模式。
- 访问不存在的作品 ID 时显示可恢复的 404 状态，不依赖后端。

## 组件与数据边界

- `WorksApp.vue`：路由状态、搜索状态、虚拟列表窗口、列表/详情模式切换。
- `works-data.ts`：Demo 作品类型、种子数据、批量生成和搜索函数；不读取网络或 Server API。
- `works.css`：仅作用于作品广场的样式、响应式布局、动画和 reduced-motion 适配。
- `index.astro` / `[workId].astro`：页面 SEO 标题、认证壳和 Vue 挂载入口。

## 视觉方向

采用“午夜档案馆”方向：近黑色画布、骨白正文、低饱和灰绿层次，以荧光黄绿作为少量交互信号；等宽小标签强调作品索引感，衬线大标题负责沉浸感。背景使用细微网格和局部光晕增加深度，不使用通用白底卡片或高饱和渐变。

## 状态、可访问性与验证

- 覆盖加载、正常列表、搜索无结果、未知详情、键盘返回和窄屏布局。
- 卡片使用真实链接语义；搜索输入、返回操作和详情区域提供可读的 ARIA 标签。
- 尊重 `prefers-reduced-motion`，并保持焦点可见。
- 增加纯函数数据测试，运行 Web typecheck、test、build，并用 `git diff --check` 检查改动。
