# 大纲拖拽视口稳定与横轴圆角设计

## 目标

完成两项横轴画布体验优化：

1. 拖动物料生成或移除虚影节点时，保持当前画布位置和缩放不变。
2. 将横轴共享分支的正常可见圆角提升到 24px，同时保持从父节点直接出线。

## 问题证据

浏览器复现显示：用户将画布缩小到 `0.472222` 后，拖动物料悬停到有效节点会加入临时预览节点，随后 zoom 自动跳到 `0.68`。

只读探针确认：

- VueFlow DOM 实例没有重挂载。
- 预览节点加入期间额外调用了 1 次 `fitView`。
- 触发链为 `preview node update → nodes-initialized → handleNodesInitialized → fitView`。

## 视口稳定设计

### 规则

- 同一个连续活跃的 `OutlineView` 只允许 `nodes-initialized` 自动执行一次 `fitView`。
- 同一视图内增删临时预览节点不得触发新的 `fitView`。
- 同一视图内正式加入物料同样保持当前 viewport。
- 每次切换到另一个视图（包括切回先前视图）时，允许新挂载的视图完成一次初始化适配。
- 用户点击重布局按钮时仍显式执行 `fitView`。

### 实现

在 `StoryOutlineCanvas.vue` 中记录最近完成初始化适配的视图。`handleNodesInitialized` 收到同一视图的后续事件时直接返回；视图变化时才允许重新适配。

不使用“仅当 materialPreview 非空时跳过”的判断，因为预览移除也会再次更新节点集合。也不完全删除初始化适配逻辑，以保留首次进入和视图切换的确定行为。

## 24px 圆角设计

### 现状

横轴路由配置为 14px，但共享 twig 在转角前只预留 14px 线段。渲染器会把圆角限制为相邻线段长度的一半，因此正常可见圆角约为 7px。

### 规则

- 横轴分支路由的目标圆角半径改为 24px。
- 正常 twig 在拐角前预留至少 48px 的直线距离，使渲染器可以绘制完整 24px 圆角。
- 线段不足时继续使用现有自适应缩小逻辑，避免圆弧反折、越界或穿过节点。
- 公共 backbone 继续使用父节点出口 X 坐标，不恢复水平引线。
- 纵轴、鱼骨图、逻辑图和思维导图不改变。

## 验证

### 自动化

- 横轴布局测试断言分支 `cornerRadius` 为 24。
- 正常 twig 的转角前线段长度至少为 48px。
- 分支仍然正交，backbone 第一段仍直接沿 Y 轴离开父节点。
- 运行完整 Web 测试、类型检查、lint、格式检查和构建。

### 浏览器

- 手动改变 zoom 后拖动物料，预览出现和消失前后 zoom、x、y 均保持不变。
- 切换视图后仍会进行一次正常适配。
- 横轴共享分支路径保留直接出线，并显示更大的圆角。
- 桌面和窄屏下无横向溢出或控制台错误。

## 完成标准

- 物料拖拽不再造成画布自动放大、缩小或跳位。
- 横轴共享分支正常场景显示完整 24px 圆角。
- 首次进入、视图切换和手动重布局行为保持正常。
