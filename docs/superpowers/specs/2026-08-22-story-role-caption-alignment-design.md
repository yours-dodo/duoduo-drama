# 角色卡片人物名称居中设计

## 目标

在故事项目的角色列表页中，让每张角色卡片下方的人物名称在标题区域内水平居中、垂直居中。单行与多行名称应保持一致的视觉位置。

## 现状

角色名称由 `StoryRolesWorkspace.vue` 中的 `.story-role-card-caption` 容器承载。现有样式使用 `text-align: center`，只能保证文字水平居中；标题区域没有统一的可对齐高度，也没有垂直方向的对齐规则。

## 方案

仅调整 `.story-role-card-caption` 的样式：

- 为标题区域设置足以容纳两行名称的统一最小高度。
- 保留 Grid 布局，使用 `place-items: center` 同时完成水平和垂直居中。
- 保留现有字体、颜色和角色卡片交互，不调整组件结构、数据或路由。

## 响应式与边界行为

- 桌面端和窄屏端使用相同的居中规则。
- 较长名称换行时，整块文字仍在标题区域内居中。
- 卡片展开、悬停和键盘焦点行为保持不变。

## 验证

- 运行 Web 工作区格式检查或仓库格式检查，确保 CSS 符合现有格式规范。
- 运行 Web 工作区类型检查，确认样式改动没有影响构建。
- 在正常桌面宽度与窄屏宽度检查角色列表页，确认单行和多行人物名称均水平、垂直居中。
