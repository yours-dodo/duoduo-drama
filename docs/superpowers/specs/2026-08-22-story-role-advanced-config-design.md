# 角色编辑高级配置折叠设计

## 目标

在角色编辑页中，将“声音与表达”模块归入“高级配置”，并让该区域默认折叠，减少首次进入页面时的视觉与滚动负担。用户展开后仍可编辑全部声音与表达字段。

## 交互方案

使用组件内的自定义折叠盒，而不是原生 `details`：

- 模块顶部使用按钮式标题栏，主标题为“高级配置”，保留 `03 / 声音与表达` 作为上下文标签。
- 组件状态由 Vue `ref(false)` 管理，默认关闭；点击标题栏切换展开与收起。
- 标题栏同步 `aria-expanded`，并通过 `aria-controls` 关联内容区域；内容区域在收起时不展示。
- 标题栏支持键盘聚焦与 Enter/Space 激活，视觉上提供展开方向提示。

## 数据与保存

只改变展示状态，不改变 `draft.speechProfile` 数据结构、字段绑定、添加/移除操作或保存请求。折叠时字段仍保留在表单中，已有编辑内容不会被重置。

## 响应式与边界行为

- 桌面端与窄屏端使用同一折叠状态和交互。
- 收起时仅显示模块标题栏；展开后恢复现有字段间距和重复项布局。
- 页面重新加载时恢复默认收起，不持久化展开状态。

## 验证

- 检查格式与类型，确保模板和样式改动无诊断。
- 运行 Web 测试，确认已有角色编辑逻辑不受影响。
- 通过开发路由 smoke check，并检查默认收起和展开后的 DOM 状态。
