# 故事大纲删除幕与章节设计

## 目标

为大纲左侧目录补充删除幕和删除章节能力。删除幕时不删除已有章节和 Beat，而是将章节迁移到相邻幕；删除章节时级联删除其 Beat，并在执行前二次确认。现有自动保存和画布布局机制继续复用。

## 交互设计

- 每个幕目录行提供删除图标按钮，按钮名称包含幕标题，保证键盘和读屏用户能够识别目标。
- 点击删除按钮后显示二次确认，说明待删除幕的章节数量和迁移目标幕。
- 确认后一次性完成章节迁移和幕删除；取消时不修改任何数据。
- 只有一个幕时禁用删除按钮，并用提示说明故事至少需要保留一个幕。
- 删除完成后选中迁移目标幕，并触发画布聚焦；如果当前选中的是被迁移章节或其 Beat，则保留当前选择。

## 相邻幕选择规则

- 优先选择待删除幕的前一幕。
- 删除第一幕时选择后一幕。
- 只剩一个幕时不允许删除，因此目标幕始终存在。
- 相邻关系按规范化后的幕 `order` 与 `id` 稳定排序计算，不依赖数组偶然顺序。

## 数据迁移规则

将迁移实现为无 UI 副作用的纯函数，输入叙事文档与待删除幕 ID，返回新的规范化文档和迁移结果。Vue 组件只负责确认交互、替换文档和更新选中状态。

迁移按以下顺序执行：

1. 找到待删除幕与目标相邻幕；目标不存在时返回不可删除结果。
2. 获取目标幕已有章节和待删除幕章节，分别按 `order`、`id` 稳定排序。
3. 将待迁移章节的 `arcId` 改为目标幕 ID，并追加到目标幕已有章节之后。
4. 将目标幕全部章节的 `order` 重新编号为从 0 开始的连续整数。
5. 删除目标幕之外的待删除幕记录。
6. 重建 `story.arcIds` 和每个幕的 `chapterIds`，并重新编号剩余幕的 `order`。
7. Beat 保留原 `chapterId`，因此随章节自然迁移；剧情物料和引用数据不改变。

整个操作只在内存中提交一次，现有深度监听随后触发一次自动保存。迁移过程中不产生孤立章节，也不先保存中间状态。

## 实现边界

- 纯函数放在叙事文档状态模块中，避免把数据完整性规则写进 Vue 模板事件。
- 不引入新依赖，不修改服务端接口和存储格式。
- 继续使用当前叙事文档 schema；`arcId`、`arcIds`、`chapterIds` 与 `order` 已能表达迁移结果。
- 不增加撤销栈；二次确认是本次范围内的误操作防护。

## 异常与边界情况

- 幕 ID 不存在：不修改文档，并向界面返回失败结果。
- 只有一个幕：不修改文档，删除按钮保持禁用。
- 空幕：直接删除并选择相邻幕。
- 目标幕已有章节：迁移章节追加在现有章节之后，保持两组各自原有顺序。
- 当前选中被删除幕：切换到目标幕；当前选中其他实体时保持不变。

## 章节删除交互

- 每个章节目录行右侧提供删除图标按钮，按钮名称包含章节标题。
- 点击删除按钮后显示二次确认，明确章节标题和将被级联删除的 Beat 数量。
- 取消确认时不修改文档、选择状态或位置覆盖。
- 允许删除某一幕的最后一个章节；删除后该幕显示为空，并继续提供“添加章节”入口。
- 删除完成后，如果当前选中的是被删除章节或其 Beat，则选中该章节所属幕并聚焦；其他选择保持不变。

## 章节级联删除规则

章节删除实现为无 UI 副作用的纯函数，输入叙事文档与章节 ID，返回新的规范化文档、所属幕 ID 和被删除的 Beat ID。

删除按以下顺序执行：

1. 找到目标章节和所属幕；章节不存在时返回未删除结果。
2. 收集所有 `chapterId` 指向目标章节的 Beat。
3. 从章节集合中删除目标章节，从 Beat 集合中删除收集到的 Beat。
4. 将所属幕剩余章节按 `order`、`id` 稳定排序，并把 `order` 重新编号为从 0 开始的连续整数。
5. 通过文档规范化重建所有幕的 `chapterIds` 和剩余章节的 `beatIds`，避免陈旧引用。
6. 清理章节及其 Beat 的画布位置覆盖，让画布立即移除对应节点和连线。

整个操作一次性替换内存文档，由现有深度监听触发自动保存，不暴露删除章节但尚未删除 Beat 的中间状态。

## 章节删除边界

- 章节 ID 不存在：不修改文档，并返回失败原因。
- 章节没有 Beat：仅删除章节并重新编号同幕剩余章节。
- 章节是幕内最后一个章节：允许删除，所属幕保留为空幕。
- 当前选中被删除章节或其 Beat：切换到所属幕；其他选择不变。

## 验证

- 单元测试覆盖删除中间幕、删除第一幕、删除最后一幕、删除空幕和仅剩一个幕。
- 单元测试验证章节全部保留、`arcId` 正确、章节顺序连续、Beat 关系不变，以及 `story.arcIds`、`chapterIds` 无陈旧引用。
- 单元测试覆盖级联删除有 Beat 的章节、删除无 Beat 的章节、删除幕内最后一个章节和不存在的章节 ID。
- 单元测试验证被删除 Beat 不再存在、同幕章节顺序连续、`chapterIds` 和 `beatIds` 无陈旧引用。
- 组件或浏览器验证幕与章节删除按钮、禁用态、确认与取消、删除后的目录和画布更新。
- 运行 Web Vitest、类型检查、Prettier 和 `git diff --check`。
