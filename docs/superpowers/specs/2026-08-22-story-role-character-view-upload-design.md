# 角色人物视图上传设计

## 目标

在角色编辑页“典型台词”模块下新增“人物视图”上传区，使用固定 16:9 预览比例。图片上传后可以预览、替换或移除，并在保存角色后持久化；下次打开角色时继续显示已保存图片。

## 数据模型与接口

- 在 `StoryRoleAsset` 上新增可空的 `viewAssetId` 字段，并建立与项目 `Asset` 的独立关系。
- 扩展领域快照、创建/更新 mutation、HTTP DTO、输出映射和 Web `StoryRoleAsset` 类型。
- 复用现有角色资产上传 URL、完成上传和下载 URL 流程；沿用同项目图片资产校验与权限边界。
- 更新角色保存请求，使 `viewAssetId` 在上传完成后随角色保存绑定；移除时提交 `null`。
- 增加数据库迁移与领域/应用测试，覆盖绑定、替换、移除、跨项目资产拒绝和并发版本校验。

## 编辑页交互

- 在“典型台词”之后新增“人物视图”区块，显示已保存图片或空状态上传盒。
- 预览容器使用 `aspect-ratio: 16 / 9`，图片 `object-fit: cover`；支持 JPG、PNG、WebP，沿用现有 20MB 上限。
- 上传阶段显示进度并禁用冲突操作；上传失败显示可重试错误。
- 新上传先绑定到本地草稿状态，点击“保存角色”才提交 `viewAssetId`；取消编辑不修改角色关联。
- 替换和移除只更新草稿关联，保持与角色封面一致的预览、撤销和保存语义。

## 边界与兼容

- 老角色没有人物视图时字段为 `null`，不影响现有角色列表、封面和语音表达数据。
- 页面重新加载时从服务端输出恢复已保存视图；上传预览 URL 在组件卸载或替换时释放。
- 桌面和窄屏使用同一数据流，窄屏仅调整布局，不改变 16:9 比例。

## 验证

- 运行 Prisma/服务端相关测试与迁移检查。
- 运行 Web 格式、类型和测试检查。
- 对角色编辑路由执行 smoke check，并验证上传盒、空状态和已保存图片的 DOM 结构。
