# 故事基础信息页头对齐设计

## 目标

让故事基础信息页的模块标识与世界观、角色资产页使用同一条顶部工具栏基线，并精简基础信息正文顶部的重复信息。

## 设计

- 将 `项目起点 / BASIC INFO` 从 `StoryBasicInfoWorkspace` 的正文区域移到 `StoryProjectView` 的顶部工具栏。
- 顶部工具栏沿用世界观和角色资产已有的 `story-project-module-kicker` 样式与位置，不新增视觉变体。
- 从基础信息正文区域删除“故事基础信息”、说明句“先确认故事的名字和表达，再让 AI 归纳时代与内容标签。”以及该区域的保存按钮。
- 移除不再需要的页头容器与对应专用样式，让表单成为基础信息工作区的首个可见内容。
- 不修改表单字段、标签生成、数据加载、保存接口或其他故事模块。

## 验收标准

- 基础信息、世界观、角色资产三个模块的双语标识出现在顶部工具栏的同一位置。
- 基础信息正文不再显示标题、说明句或保存按钮。
- 基础信息表单仍能正常加载，现有字段与标签交互不受影响。
- 桌面和窄屏布局没有新增溢出或错位。

## 验证

- 运行 Web 工作区格式检查或 Prettier 校验。
- 运行 `pnpm --filter @duoduo/web typecheck`。
- 在桌面宽度与窄屏宽度检查目标路由。
