# 首页“多多文创”定位调整设计

## 背景

首页当前以“多多剧场”为品牌，叙事集中在故事开发、有声小说和 AI 短剧。产品需要在首页体现“多多文创”的更宽内容生产定位，同时保留现有创作能力和入口。

## 目标

- 仅调整首页对外呈现，将品牌名和首页内容定位统一为“多多文创”。
- 将首页表达从单一“剧场”扩展为文化内容创作、孵化与生产平台。
- 保留故事创作、有声小说和 AI 短剧作为当前可用的内容形态和业务入口。
- 不改变现有路由、接口、权限、主题切换或工作台行为。

## 非目标

- 不修改登录页、工作台、故事页、短剧页或管理后台的品牌文案。
- 不新增 IP 管理、内容发布、作品广场或其他尚未实现的业务能力。
- 不重做首页视觉布局，不引入新的图片、字体或后端数据。

## 方案

### 首页文案

在 `apps/web/src/pages/index.astro` 中调整：

- 页面标题、描述、关键词和 JSON-LD 结构化数据中的品牌名与定位。
- Hero 标题及介绍，突出从灵感/IP 到多元内容表达的路径。
- 故事项目、故事资产、内容形态、生产流程、创作工作流和能力区的说明，将“故事”放在“文化内容项目”的语境中。
- 有声小说和 AI 短剧卡片继续保留，原有 `/stories`、`/dramas` 链接不变。
- 底部 CTA 改为面向内容创作与生产的表达，两个现有入口继续可用。
- 仅保留“雨停之前”等示例项目作为视觉样例，不将示例描述包装成新的实际业务承诺。

### 首页专属品牌传递

`SiteHeader`、`SiteFooter` 和 `BaseLayout` 是跨页面共享组件，不能直接把共享默认品牌全局替换。为避免影响非首页页面：

- `BaseLayout` 根据 `pageClass === 'landing-page'` 传递首页品牌名。
- `SiteHeader` 与 `SiteFooter` 增加可选品牌属性，默认仍为“多多剧场”。
- 首页显示“多多文创”，其他页面继续显示“多多剧场”。
- 页脚版权文本的产品标识同步按首页品牌显示，但不改其他页面的产品标识。

### 可访问性与 SEO

- 更新首页品牌相关的 `aria-label`、图片/视觉示例描述和页面核心可见标题。
- 保持首页核心标题、描述、导航、CTA 和社交/结构化元数据在初始 HTML 中可见。
- 不新增依赖 JavaScript 才能呈现的首页核心信息。

## 兼容性与风险控制

- 所有原有首页链接保持不变，避免影响已有创作入口。
- 共享组件的品牌属性采用默认值，降低其他页面回归风险。
- 只做中文文案和品牌参数调整，不触碰业务状态、数据流和样式结构。

## 验证方案

- 使用 `rg` 检查首页渲染相关内容中的“多多剧场”已替换，确认非首页页面仍保持原品牌。
- 运行 `pnpm --filter @duoduo/web typecheck`、`pnpm --filter @duoduo/web test` 和 `pnpm --filter @duoduo/web build`。
- 按 Web 项目规范检查首页桌面宽度和窄屏宽度，确认标题、按钮和卡片文案无溢出或异常换行。
- 执行 `git diff --check`，并确认提交只包含本设计文档或后续明确的首页实现文件。
